# Operator Console Screenshot Checklist

This directory is reserved for real screenshots captured from a running
NetworkOps AI Agent Operator Console. Do not add generated images, empty PNGs,
mockups, or placeholder screenshots.

Required files for a future showcase update:

- `dashboard.png` — overall incident and operational health summary.
- `incidents.png` — incident list, filters, and selected incident details.
- `trace.png` — Agent/node/tool execution trace and latency.
- `governance.png` — projected governance and security events.
- `policy.png` — ALLOW, DENY, and REQUIRE_APPROVAL decisions.
- `evaluation.png` — offline RCA, retrieval, safety, and latency evaluation.

Before capture, use only synthetic demo data, hide the browser's Authorization
header, and verify that no JWT, credential, secret, personal information, or
environment configuration is visible. Keep a consistent viewport and theme.
